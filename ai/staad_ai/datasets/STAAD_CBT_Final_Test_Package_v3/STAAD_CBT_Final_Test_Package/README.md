## Baseline policy
Do not edit the baseline files. Make all corrections or evidence-backed improvements in a new candidate version. The baseline metadata stores SHA-256 hashes for integrity checking.

## Status
AI-generated and unvalidated. Source mappings have mixed support status and are not a clinical approval. Exact passage verification is incomplete for some claims. Qualified clinician review, local protocol review, and live retrieval tests are pending.

## Safety
The Copilot supports professionals and must not autonomously diagnose, prescribe, change medication, select treatment or replace professional assessment. Use approved local crisis/safeguarding protocols. Synthetic graph examples only; never use real client data in test fixtures.
