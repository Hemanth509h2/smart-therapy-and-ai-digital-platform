# Intellectual Disability Knowledge Base

- Original baseline: 45 source-linked, paraphrased records.
- Testing candidate: same 45 claims plus retrieval metadata.
- Baseline files are preserved separately from candidate files.
- Source IDs point to the source register in `sources_and_references.json`.
- These records are a preliminary engineering dataset, not a clinically approved knowledge base.
- `source_locator` is a section/topic locator, not a verified quote-level pinpoint citation. Verify each claim against the live source text before clinical use.
- Records about STAAD safety requirements are explicitly marked as engineering controls rather than claims directly quoted from clinical sources.
